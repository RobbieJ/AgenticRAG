# Brand assets

Drop the **official Red Hat logo** here as:

    redhat-logo.svg   (preferred)  — or redhat-logo.png

The header (`components/Header.tsx`) loads `/brand/redhat-logo.svg` automatically.
Until that file exists, the header falls back to a plain text wordmark — we never
recreate the Red Hat logo in code.

Obtain the approved logo from the Red Hat brand portal / your brand team and place
the exact, unmodified asset in this folder.
